# P2 证据组合实验：事先登记（2026-11-06，运行任何实验之前写定）

## 问题
在不改变"语言模型证据 → 校准 → Soft F1"设计的前提下，哪些不依赖 Gold 的 NLP 特征与 BERT 证据结合，
能最有效、且最能跨领域泛化地评估切分质量？

## 数据
仅 GUM train（197 篇、15 个 genre）。GUM dev 不用于选型；GUM test 不读；EWT test 留到冻结后只跑一次。

## 两种交叉拟合
- 5 折（与 P1 相同的分层折）：领域内表现。
- **留一领域（LOGO，15 折）**：校准器从未见过被评领域，用来近似"新领域"。**选型以 LOGO 为准。**

## 选型标准
1. 主指标：LOGO 上的领域平均（所选 − Always-SaT）Macro Gold F1。
2. 次指标：LOGO 上的 Gold-win 率。
3. 若主指标与更简单的配置之差小于 0.002，或配对 bootstrap 95% CI 跨 0，则选特征组更少的配置。
4. 使用候选系统投票（V 组）的配置违反"证据独立于候选"的原则，只报告，不参与选型。
5. Soft F1 公式、候选系统、Direct Internal 阈值 0.5 不变。

## 特征组（全部只由原始文本、空隙位置和 BERT 原始概率计算）
- B：BERT 原始概率的 logit 与 mask 模式（B 单独 = Platt 基线）
- C：左侧上下文类别（终止单元 / 无标点 / 破折号 / 冒号 / 分号 / 逗号）及其与 logit 的交互
- K：左右词形（首字母大写、全大写、小写、数字、开引号或括号）及与上下文类别的交叉
- A：缩写线索（Kiss & Strunk 式文档内类型统计：该词在本文档中不带句点出现的比例、词长、内部句点）
- L：版面与片段特征（距上一个/下一个终止标点的词数、左右片段的标题式大写比例）
- V：候选系统在该空隙的投票数（仅作对照）

## 修订 1（2026-11-06，第一轮正式结果出来之前写定）
此前只看过一次两配置的干跑（platt 与 B+C+K），据此注意到：证据作为切分器明显变强，但选择指标几乎不变。
据此新增两组特征。选型规则不变，新配置与第一轮一起按同一规则比较：
- O：Punkt 式文档内正字法统计（右侧词在本文档中通常小写、在句中位置是否也大写）
- W：左右词的词汇先验（类别特征，只在训练折上做目标编码，内部再交叉拟合）

## 修订 2（2026-11-06，计算任何新指标之前写定）：主目标更正
用户更正：主目标是**指标能跨领域、跨文档识别和比较分句质量，尤其是质量差别大时**；选出更好的 splitter 只是副任务。
另外，证据不应使用大小写线索（BERT 选 uncased 是有意为之）。因此：
- K、O 以及 L 中的标题式大写比例使用了大小写，相关配置只作分析，不作为方法候选。
- 此后所有实验的**主指标**：所有（文档，系统）条目上，指标分数与 Gold F1 的全局 Spearman ρ（跨文档）。
- 辅助指标：
  - 全部条目两两配对（含跨文档配对）的 pairwise accuracy，按 |ΔGold F1| 分档（<0.02、0.02–0.05、0.05–0.10、≥0.10），重点看 ≥0.05；
  - 领域 × 系统层面（各格的平均分 vs 平均 Gold F1）的 Spearman；
  - 原有的文档内 pairwise、领域内 τ、Selection Regret 作为次要诊断。
- CI：按领域分层、按文档重采样的 bootstrap；比较两个评分函数时用配对 bootstrap。

## 修订 3（2026-11-07，写任何新代码、看任何新结果之前写定）：让证据区分“标点”与“句子边界”
问题：BERT 的 [MASK] 标点概率回答的是“这里该不该有 .?!”，不是“这里是不是句子边界”；无终止标点的 Gold 边界
（约 9.8% 的 Gold）平均 p 只有 0.2–0.3，上限诊断表明这是决定性误差。三种方法与一个控制变量实验，同一 GPU 作业：

- 冻结 `bert-base-uncased`、v1.1 查询协议、原文上下文（`raw`）不变；候选、Soft F1 不变。
- **platt**：特征 = logit(p_punct)（基线，在本作业内重算）。
- **方法 2 `lr`**：插入句号的似然比。每个空隙两种渲染：A = 空隙处有终止标点（原有的保留，否则插入 “.”），B = 无
  （原有的删除，否则不变）；在同一窗口中依次 mask 空隙左侧 2 个、右侧 3 个 token，记录 log p(原 token)。特征 =
  logit(p_punct) + 5 个 Δ = log p_A − log p_B + 有效性标记 + 左右 Δ 之和。
- **方法 1 `probe`**：特征 = logit(p_punct) + [MASK] 位置第 8 层与第 12 层隐状态（1536 维），L2 逻辑回归探针。
- **方法 1+2 `probe+lr`**：两者特征拼接。
- 所有配置都用同一个 L2 逻辑回归（特征按训练折标准化，均值损失 + λ/2‖w‖²）。platt / lr：λ = 1e-6；probe 类：
  **主设定 λ = 1e-3**，λ ∈ {1e-4, 1e-2} 只作敏感性分析（只报点估计，不参与选型）。
- **控制变量实验 4 `para`**：把 GUM 原文的段落分隔（CoNLL-U `# newpar`）以 `[SEP]` 写入 BERT 输入，其余完全
  相同，四种配置各跑一遍。注意：GUM 中段落分隔按构造必然是句子边界，这等于把这部分边界信息交给证据；只作分析，
  是否作为方法由用户决定，不参与本修订的选型。
- 交叉拟合：P1 的 5 折与 LOGO（15 个领域）各一套，每篇文档的证据只来自没见过它的折；只用 GUM train。
- **主判据**：LOGO 下归一化 Soft F1 的全局 Spearman，与同一作业内的 platt 做配对 bootstrap（1000 次，领域内
  分层按文档重采样）。一个方法“有效”= 配对差 95% CI 全在 0 以上；有效方法中取点估计最高者，与更简单配置之差
  < 0.01 时取更简单者（简单程度：platt < lr < probe < probe+lr）。
- 辅助：大差距配对（|ΔGold F1| ≥ 0.05）、领域×系统 Spearman、文档内配对、原版 Soft F1 的同组指标；诊断：
  无终止标点的 Gold 边界与有终止标点的非 Gold 空隙上的平均 p。

## 修订 4（2026-11-08，运行 EWT test 之前写定）：冻结方法与 EWT 一次性测试
用户决定：**主方法 = 不带版面信息的 `raw/probe+lr`**（修订 3 按规则选中）；带版面信息的 `para` 只作补充实验。

冻结内容（此后不再改动）：
- 证据：冻结 `bert-base-uncased`、v1.1 查询协议、原文上下文；探针特征 = logit(p_punct) + [MASK] 处第 8/12 层隐状态
  + 插入似然比特征；L2 逻辑回归 λ = 1e-3，在**全部 197 篇 GUM train** 上拟合一次（不再交叉拟合）。
- 评分：归一化 Soft F1（主），原版 Soft F1（辅）。候选系统与设置不变（Punkt / Stanza / WtP / SaT 默认参数）。
- 同时报告的对照（同样在全部 GUM train 上拟合）：raw/platt（基线）、raw/lr、raw/probe，以及四种配置的 `para` 版本。

EWT test（UD English EWT r2.18，`en_ewt-ud-test.conllu`，316 篇、5 个领域）：
- 全部 316 篇文档都参与，不做筛选；领域 = 文档 id 中第一个 “-” 之前的前缀。
- 流程：原文重建 → 切分器 → 证据 → 写盘冻结全部分数 → 之后才物化 EWT Gold → 分析。只运行一次；看到结果后不再调整
  任何设置。
- **主判据**：归一化 Soft F1 的全局 Spearman，`raw/probe+lr` 相对 `raw/platt` 的配对差（领域内分层、按文档重采样
  1000 次）。配对差 95% CI 全在 0 以上即认为改进在跨语料测试上成立。
- 辅助：大差距配对（|ΔGold F1| ≥ 0.05）、领域×系统 Spearman（5 × 4 个单元）、文档内配对；选择类指标（领域平均
  所选 − 永远 SaT、Gold-win）作次要诊断；无终止标点 Gold 与带终止标点非 Gold 上的平均 p。
- `para`：EWT 的段落标记（`# newpar`）同样按构造位于句子起点，只作补充，不参与主判据。

## 修订 4a（2026-11-08，EWT 分数已冻结、任何 EWT 指标计算之前写定）：无空白位置的 Gold 边界
EWT 作业 22337008 在物化 Gold 时停止：EWT 中有 Gold 句子边界位于两个 token 之间且没有空白（GUM 中不存在这种情况，
旧代码因此直接报错）。此时全部分数已冻结，没有计算任何指标；只统计了数量：1761 个 EWT Gold 边界中有 12 个
（0.68%，8 篇文档）属于这种情况。处理规则：
- 这些位置不是候选空隙，没有证据，也不进入 Soft F1（与切分器在非空白位置的切分一致），冻结分数不变。
- Gold F1 按真实边界精确计算：切分器在同一非空白偏移处的切分记为 TP（而非 FP），未被切到的此类 Gold 边界记为 FN，
  其余非空白位置的切分仍记为 FP。GUM 上没有此类 Gold 边界，此前所有结果不受影响。
- 其余协议（修订 4）不变；只补跑 Gold 物化与分析两个阶段，不重新计算任何证据或分数。

## 修订 5（2026-11-08，计算任何基线数字之前写定）：无参考基线对照
目的：检验主方法是否优于不需要 BERT 的简单无参考替代方案，并说明这些替代方案的局限。三类基线都不需要训练
（长度基线只用 GUM train Gold 定一个常数），因此在 GUM train（开发集）和 EWT test 上直接计算；EWT 上的基线
对照是在 EWT 测试之后补加的比较，主方法与其结果均不改动。

- **B1 单系统伪参考**：以系统 R ∈ {Punkt, Stanza, WtP, SaT} 的输出为参考答案，条目分数 = 该系统切分对 R 的边界
  F1（全部切分点，含非空白位置）。R 自身的条目恒为 1，因此对每个 R 另在“去掉 R 自身条目”的子集上与主方法比较。
- **B2 留一共识**：系统 S 的参考答案 = 其余三个系统的多数票（≥ 2 票），条目分数 = S 对它的边界 F1。
- **B3 启发式**：(a) 标点规则伪参考：参考答案 = 左侧为终止单元的全部空白空隙，分数 = 边界 F1；
  (b) 句长合理度：−|log(平均句长 / L0)|，L0 = GUM train Gold 句长中位数（token）。
- 主方法：`raw/probe+lr` 的归一化 Soft F1（GUM 用 LOGO 交叉拟合证据，EWT 用冻结证据）；同时列 `raw/platt`。
- 指标与 CI 同修订 2（全局 Spearman 为主；配对差 = 基线 − 主方法）。
- 动机分析（只作分析）：(1) 所有系统一致犯的错（共同漏切的 Gold 边界、共同多切的非边界）上，基线与证据各自能否
  察觉；(2) 每个系统内部跨文档的 Spearman（“这个系统在哪些文档上切得差”）；(3) 按领域；(4) 主方法与共识的
  秩平均，检验二者是否互补。
- 修订 5 补充（看过上述基线结果之后加，**事后分析**）：(5) 秩平均相对共识本身的配对差（检验互补）；
  (6) 各评分在语料级与领域级把哪个系统排第一，及其相对 oracle 的 regret（共识是否偏向“中间派”）。
- 修订 5 补充 (7)（事后分析）：把跨文档一致性分解为“文档之间”（文档平均分 vs 文档平均 Gold F1 的 Spearman）与
  “文档之内”（减去文档均值后的 Spearman），并报告 Gold F1 方差中文档间差异的占比；配对 bootstrap 同修订 2。

- 开发：GUM train 197 篇，**LOGO（15 折）为准**；GUM dev 不用；GUM test 不读；EWT 不再使用（已一次性测试过）。

### 组件（超参数全部事先固定，不调参）
空隙层证据（每个都在 GUM 上 LOGO 交叉拟合，或零样本 + LOGO Platt）：
- **E0** `probe+lr`：冻结的主方法（修订 4），沿用已有 LOGO 证据。
- **E1** `sat12l`（课程 L3/L7 序列标注；L13 深度学习）：`sat-12l`（无 `-sm`，只在网页文本上自监督训练，未见过 UD）
  对小写原文的字符级概率，空隙概率 = max(左侧末字符, 空白字符)；stride 64、block 512；再做 LOGO Platt。
  `sat-12l-sm` 只作分析（GUM 上被污染），不参与选型。
- **E2** `ft-modernbert`（L7 BIO 式逐 token 标注）：`answerdotai/ModernBERT-large`，小写输入，按空白切词，每个词的最后
  一个子词预测"其后空隙是否为边界"；窗口 512 子词、步长 256（预测取窗口中段）；lr 2e-5、3 个 epoch、batch 16、
  warmup 10%、weight decay 0.01、种子 20261102；训练时以概率 0.3 删掉 Gold 边界前的终止标点（SaT 式腐蚀，仅训练）。
  LOGO 15 折各训练一次；测试用全部 GUM train 训练一次。输出再做 LOGO Platt。
- **E2b** `ft-bert-uncased`：同一配方换成 `bert-base-uncased`，只作消融（冻结探针 vs 微调），不参与选型。
- **R** 规则特征（L2 正则 / 有限状态机）：左侧上下文类别（C 组的 one-hot）、缩写线索（A 组，不含大小写）、
  序号/列表标记、单字母缩写、数字与时间表达式、右侧为闭合标点或逗号、到相邻终止单元的距离（L 组前两列）。
- **N** n-gram 特征（L5 n-gram 语言模型）：在训练折 Gold 句子上训练小写词级插值 Kneser–Ney 三元模型（含 `<s>`、`</s>`），
  特征 = log P(`</s>`|w₋₂w₋₁)、log P(w₊₁|`<s>`)、log P(w₊₁|w₋₂w₋₁) 及似然比。
- **stack**（L6/L7 MaxEnt）：L2 逻辑回归（λ = 1e-3，标准化），特征 = E0、E1、E2 的 logit + R + N；在各基础证据的
  LOGO 折外预测上再 LOGO 拟合。
- **结构化后验 `+hsmm`**（L3 HMM / 前向-后向）：半马尔可夫模型，句长（词数）分布取训练折 Gold（加 0.5 平滑，
  上限 200），发射为证据几率除以训练折先验几率；精确前向-后向得到每个空隙的后验边界概率。

条目层评分：
- 单系统线（只需被评系统的输出）：**S0** = E0 归一化 Soft F1（冻结主方法）；**S1** = 选中证据的归一化 Soft F1；
  **S2** = QE 回归（L6 回归）：岭回归（λ = 1，标准化，LOGO）预测 Gold F1，特征 = 选中证据下的 Soft F1、归一化
  Soft F1、文档最大 Soft F1、文档特征（证据熵均值、每词 Σp、无终止标点空隙上的 p 质量占比、log 空隙数、终止标点
  密度）、候选特征（每词边界数、切在无终止标点空隙上的比例、每词 Σ_切(1−p)、每词 Σ_未切 p）与扰动稳定性；
  不含系统身份。
- 多系统线（需要其他系统）：**M0** = 留一共识（修订 5 的 B2）；**M1** = Dawid–Skene（L3 EM）：四个系统为标注者，
  每个系统按"左侧是否为终止单元"两层各估计敏感度与特异度，先验为单一基率，EM 以多数票初始化、迭代 200 次，在
  目标语料上无监督拟合；被评系统的分数 = 去掉它自己的投票后的后验上的 Soft F1；**M2** = 同 M1，但每个空隙的先验
  = 选中证据；**M3** = S2 的特征 + M2 分数 + 共识 F1 的 QE 岭回归。
- 扰动稳定性（自补）：把文档按 64 个词切块（起点偏移 0 与 32 两种），每块单独运行同一切分器；稳定性 = 非块边缘
  空隙上与原输出的边界 F1，两种取平均。只作为 S2/M3 的特征。

### 选型（GUM LOGO，主指标 = 全局 Spearman，配对 bootstrap 1000 次，领域内按文档重采样）
1. 证据：在 {E0, E1, E2, stack} × {独立, +hsmm} 中，取相对 E0（归一化 Soft F1）配对差 CI 全在 0 以上且点估计
   最高者；与更简单者之差 < 0.01 时取更简单者（E0 < E1 < E2 < stack；独立 < +hsmm）。
2. 单系统线 S* = {S1, S2} 中全局 Spearman 最高者（差 < 0.01 取 S1）；多系统线 M* = {M1, M2, M3} 中最高者
   （差 < 0.01 取更简单者，M1 < M2 < M3）。
3. 选型结果冻结后才运行测试。

### 判据
- **开发成功**（运行测试的前提）：S* 相对 S0、M* 相对 M0 的全局 Spearman 配对差 95% CI 都全在 0 以上；且通过公平性检查。

## 修订 8（2026-11-17，写任何新代码、计算任何新数字之前写定）：补充有效性实验
性质：全部**只作分析**，不改变修订 4/6 的冻结方法、选型与结论。所有测试集都已用过，因此 GENTLE / LinES 上的部分都是
**测试后分析**；主分析在 GUM train（LOGO 证据，开发集）上。不读 GUM dev / test；EWT 不再使用（只有 E0 证据，补算其他证据
等于第二次测试）。不重训任何神经模型；只在 CPU 上用已缓存的逐空隙证据计算。CI：领域内按文档重采样 1000 次，种子 20261102。
所有候选只在空白空隙上表示（与 Soft F1 的候选空间相同）；“真实质量” = 候选与 Gold 在空白空隙上的边界 F1。

**评分方法（统一记号）**：PuncEv = BERT [MASK] + Platt 的归一化 Soft F1（只有 GUM，5 折交叉拟合证据）；Probe = E0；
E1、E2 = 单一证据；Stack = 修订 6 选中的组合证据（均为归一化 Soft F1）；H(E0)、H(Stack) = 硬伪参考（修订 7.1）；
Rule = 以“左侧为终止单元”的空隙为参考的边界 F1（正则伪参考）；Cons = 共识（三系统多数票参考的边界 F1）；
DS = Dawid–Skene（Stack 先验）后验上的 Soft F1；LenPrior = 候选句长在 GUM-train 句长分布下的平均对数概率
（GUM 上按 LOGO 拟合）。多系统评分对真实系统 s 用去掉 s 的参考（同 M0/M2）；对 Gold 和人工候选用四个留一参考的平均。

### 8.1 Gold 作为候选（A1）
每篇文档把 Gold 当作第 5 个候选。报告每个评分方法下：Gold 胜过每个系统的比例（多系统评分用去掉该系统的同一参考比较，
平局记 0.5）、Gold 排第一的比例（胜过全部 4 个系统）。解读：排第一比例 ≥ 0.8 称“能认出 Gold”；否则写明 Gold 输给了哪个系统。

### 8.2 人工扰动的识别度与敏感性（A2，规模扩大、按类型区分）
在 Gold 上注入 k = max(1, round(r·|Gold|)) 次操作，r ∈ {0.05, 0.10, 0.20, 0.40}，每个 (文档, 类型, r) 20 个重复
（种子由 (20261102, 文档序号, 类型序号, r 序号) 决定）。类型（按左侧上下文类别，与证据缺口分析相同的无 Gold 规则）：
- **merge_terminal**：删除左侧为终止标点的 Gold 边界；**merge_other**：删除左侧不是终止标点的 Gold 边界（标题、列表、无标点等）；
- **split_terminal**：在左侧为终止标点的非 Gold 空隙插入边界（缩写、引语内句号等）；**split_punct**：在逗号/冒号/分号/破折号后的
  非 Gold 空隙插入；**split_nopunct**：在无标点的非 Gold 空隙插入；
- **shift**：把一个 Gold 边界移到 ±3 个词内的非 Gold 空隙；**mixed**：每次操作从上面 6 类中均匀抽取。
某类在文档中没有可用位置时该操作跳过；一次操作都没做成的候选不计入；可用文档数逐类报告。
指标（每个评分方法 × 类型；先在文档内计算，再对文档取平均）：
- **识别率**：Gold 分数高于扰动候选的比例（平局 0.5），按 r 分别报告；
- **单调性**：同一类型的候选与 Gold 中，真实 F1 不同的候选对里分数顺序与真实 F1 一致的比例；
- **敏感度**：文档内分数对真实 F1 的 OLS 斜率（理想 = 1）；**不对称指数** = 斜率(merge_other) / 斜率(merge_terminal)。
- **跨文档**：所有 mixed 候选与 Gold 汇总后，分数与真实 F1 的全局 Spearman（主目标的受控版本）。
预先写定的比较（配对 CI）：Stack − Probe、Stack − PuncEv（GUM）、Stack − Cons、Stack − H(Stack)，比较 r = 0.10 的识别率与各类型斜率。
解读：不对称指数 < 0.5 称该评分方法对“无标点边界被合并”**有盲区**；某类型 r = 0.10 的识别率 < 0.6 称对该类型**不敏感**。

### 8.3 真实系统错误的分类计价（A3：解释 Punkt 被高估）
对每个 (文档, 系统)，把错误分为 漏切-终止 / 漏切-其他 / 多切-终止 / 多切-标点 / 多切-无标点，逐类单独修正，记录评分变化 Δs 与
真实 F1 变化 ΔF1；奖励比 = ΣΔs / ΣΔF1（按类型、评分方法汇总）。同时报告各系统的错误构成。
解读：若 Stack 下 奖励比(漏切-其他) < 0.5 × 奖励比(漏切-终止)，且 Punkt 的漏切-其他占比在四个系统中最高，则称 Punkt 被高估
“由共同盲区解释”；否则写明。

### 8.4 原始问题的回答：选择遗憾（A4）
对 S0、S1、M0、M3（以及 GUM 上的 PuncEv）报告：语料级选择（平均分最高的系统）的 Macro Selection Regret 与 Always-SaT
的遗憾；逐文档路由（每篇选分数最高的系统）的平均遗憾与 Always-SaT 的配对差 CI。解读：只有 CI 全在 0 以下才称“优于 Always-SaT”。

### 8.5 简单基线（A5）
在真实系统条目上报告 LenPrior、Rule、DocAgree（四个系统两两边界 F1 的平均，文档内常数：只能认出难文档）的全局 Spearman、
文档之间/之内分解，以及 S1 − 基线 的配对差 CI。解读：若某个简单基线与 S1 的差 CI 跨 0，论文中必须写明。

### 8.6 Stack 去掉单一证据的消融（A6：组合证据是否偏袒同源系统）
Stack−E1、Stack−E2：同修订 6 的配方去掉对应特征列（GUM 上 LOGO；GENTLE/LinES 上用全部 GUM train 重拟合，测试后分析）。
报告全局 Spearman 与各系统平均秩残差。解读：去掉 E1 后 SaT 或 WtP 的残差变化绝对值 > 0.05，或去掉 E2 后 Stanza 的变化 > 0.05，
称该证据在 Stack 中引入了**同源偏差**。

### 8.7 文档长度（B1）
按 GUM 文档空隙数三等分，报告 S1 的全局 Spearman、文档内配对准确率，以及 mixed、r = 0.10 时 Stack 的识别率。只报告。
